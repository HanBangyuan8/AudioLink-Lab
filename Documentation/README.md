# AudioLink Lab documentation

The documentation is grouped into five maintained references instead of one
file per feature:

- [User Guide](UserGuide.md) — installation, first use, workflows, history,
  reports, troubleshooting, and limitations.
- [Measurement Reference](MeasurementReference.md) — signals, import,
  correlation, quality, calibration, visualization, adaptive planning, and
  spatial measurement.
- [Platform and Labs](PlatformAndLabs.md) — realtime audio, Core Audio,
  devices, plugins, networking, mobile, and advanced labs.
- [Security and Data](SecurityAndData.md) — privacy, protocol, bundles,
  automation, and security boundaries.
- [Developer and Validation](DeveloperAndValidation.md) — CLI, validation,
  release, performance, and engineering references.

Independent audit records remain in [Reviews](Reviews/), and screenshot
placeholders remain in [Screenshots](Screenshots/).

The repository root keeps only the project-level entry points: `README.md`,
`CHANGELOG.md`, `LICENSE`, and `CONTRIBUTING.md`.
